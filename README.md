# LaTeX Portfolio & Historical Archive

A small, chronological archive showcasing my long-term journey and experience with **LaTeX** for technical typesetting, mathematical documentation, and academic writing.

---

## Overview

This repository serves as a personal showcase of my LaTeX documents spanning several years. Rather than a curated collection of polished modern templates, it presents an authentic historical record of my document design and technical writing skills over time.

- **Using LaTeX since 2019**: I first adopted LaTeX during 9th grade in high school to type out mathematics and structured notes.
- **Pre-ChatGPT / Pre-AI Era**: A significant portion of this codebase was written well before the release of ChatGPT and generative AI coding assistants—built entirely by hand through trial, error, and manual package documentation.
- **Chronological Folder Structure**: Directory names reflect the year the code was authored (e.g., `Folder - 2021`, `Folder - 2022`) to demonstrate consistent, long-standing usage over time.

---

## What's Included

- **Exams & Midterms**: Complex test documents and collaborative exam solutions developed during university.
- **Problem Sets & Workshops**: Homework submissions, statistical reports, and coursework exercises.
- **Early High School Files**: Historical documents and early templates dating back to 2019.

---

## Stack & Tools

- **Engine / Distributions**: TeX Live, MiKTeX
- **Editors**: TeXstudio, Overleaf, VS Code / Cursor
- **Packages Commonly Used**: `amsmath`, `amssymb`, `tikz`, `pgfplots`, `babel`, `geometry`, `xcolor`, `fancyhdr`, `biblatex`
